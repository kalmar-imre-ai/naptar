## ✨ Főbb jellemzők

- 🔒 **Adatvédelem:** nincs internet engedély és nincs követés
- 📱 **Helyi adattárolás:** az adataid csak a telefonodon vannak
- ⏰ **Emlékeztetők:** értesítések a naptárbejegyzésekhez
- 🗓️ **Ünnepnapok:** magyar ünnepnapok és munkaszüneti napok

## 📥 Telepítés

### Közvetlen letöltés

1. Töltsd le a legutóbbi `.apk` fájlt a [Releases](https://github.com/kalmar-imre-ai/naptar/releases/latest) oldalról.
2. Nyisd meg a telefonon.
3. Ha kéri a telefon, engedélyezd az ismeretlen forrásból való telepítést.

### Obtainiumon keresztül

Add hozzá a tárolót az [Obtainium](https://github.com/ImranR98/Obtainium) alkalmazásban:

```
https://github.com/kalmar-imre-ai/naptar
```

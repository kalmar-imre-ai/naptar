# Naptár
Offline, személyes naptár Androidra. Nincs internet-engedély, nincs követés, az adatok csak a telefonon vannak.

## Telepítés
**Közvetlenül:** töltsd le a legutóbbi kiadás `.apk` fájlját a **Releases** oldalról, és nyisd meg a telefonon (engedélyezni kell az ismeretlen forrásból való telepítést).
**Obtainiumon keresztül:** add hozzá a tárolót: `https://github.com/kalmar-imre-ai/naptar`

## Aláírás ellenőrzése
Az alkalmazás aláírásának SHA256 ujjlenyomata (AppVerifierben ellenőrizhető):
```
E4:97:4B:01:28:AD:DD:A0:6C:EA:56:AE:4A:13:0D:C5:E6:C1:10:8C:1E:CE:F3:64:E3:5B:76:D9:DF:A8:50:E6
```

## Megjegyzés
Ez egy kísérleti, személyes célú alkalmazás. Az emlékeztetők a telefon akkumulátor-beállításaitól függően késhetnek, ezért érdemes egyszer ellenőrizni őket.
